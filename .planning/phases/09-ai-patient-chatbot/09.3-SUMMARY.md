## Router Integration Approach

**Pattern used: role-injection via AppLayout** (not Outlet wrapper).

The existing router uses a flat `<Protected role="patient"><Page /></Protected>` pattern where `Protected` renders `<AppLayout>{children}</AppLayout>`. Restructuring patient routes into a nested Outlet hierarchy would require modifying every patient route definition.

Instead, `AppLayout` reads `user.role` from the Zustand auth store and wraps `children` in `<PatientLayout>` when `role === 'patient'`. This provides layout-level chat widget availability with zero route changes.

```jsx
// AppLayout.jsx (simplified)
const isPatient = user?.role === 'patient';
const pageContent = isPatient ? <PatientLayout>{children}</PatientLayout> : children;
```

## Streaming Client Architecture

```
useChatbotStream (hook)
  └─ streamMessage (async generator)
       └─ fetch POST /api/chatbot/message
            headers: Authorization: Bearer {token}, x-api-key, Accept: text/event-stream
            └─ res.body.getReader()  (ReadableStream)
                 └─ TextDecoder({ stream: true })  (handles multi-byte chars split across chunks)
                      └─ buffer.split('\n\n')  (SSE frame delimiter)
                           ├─ data: {"type":"delta","text":"..."}  → append to assistant message
                           ├─ data: {"type":"done",...}            → set urgency/emergency/doctors
                           ├─ data: {"type":"error","message":...} → surface to user
                           └─ data: [DONE]                         → yield {type:'terminated'}, return
```

AbortController ref in hook cancels the in-flight stream on reset or if `send()` is called again.

## Hook API Surface (mirrors mobile)

```javascript
const {
  messages,   // [{ id, role: 'user'|'assistant', content }]
  streaming,  // boolean
  urgency,    // 'routine'|'soon'|'urgent'|'emergency'|null
  emergency,  // boolean
  doctors,    // DoctorObject[]
  error,      // string|null
  send,       // (text: string) => void
  reset,      // () => void — clears state + DELETE /api/chatbot/session
} = useChatbotStream({ lat, lng });
```

## Emergency Handling Flow

1. SSE `done` event arrives with `emergency: true`
2. Hook sets `emergency = true` via `setEmergency(Boolean(event.emergency))`
3. `ChatWidget` renders red `role="alert"` banner: "EMERGENCY — Call emergency services now"
4. `<a href="tel:911">Call 911</a>` link shown prominently
5. Doctor card section is conditionally skipped: `{!emergency && doctors.length > 0 && <...>}`
6. `UrgencyBadge` in header still shows "! Emergency" chip
