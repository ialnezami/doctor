## Streaming Architecture

```
ChatbotScreen
  └── useChatbotStream({ lat, lng })
        └── streamMessage() [async generator]
              └── fetch POST /api/chatbot/message
                    → ReadableStream.getReader()
                    → TextDecoder + \n\n frame split
                    → yield { type, ...payload }
                         delta  → append to assistant message content
                         done   → set urgency + emergency + doctors
                         error  → set error state
                         [DONE] → terminate generator
```

## Emergency Flow Invariant

```
event.emergency === true
  → emergencyBanner rendered (red, "Call 911")
  → doctors section suppressed (ListFooterComponent returns null)
  → NEVER show doctor cards alongside emergency CTA
```
