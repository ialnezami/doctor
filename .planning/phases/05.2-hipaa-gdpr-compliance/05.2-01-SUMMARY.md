## Summary

Built the cryptographic and audit infrastructure that all other Phase 5.2 plans depend on.

## What Was Built

- `apps/api/src/utils/fieldEncryption.js` — AES-256-GCM encrypt/decrypt. Key from `FIELD_ENCRYPTION_KEY` env (64-char hex). Returns `iv|ciphertext|authTag` pipe-delimited. Legacy plaintext passthrough (no `|` → returned as-is for migration compat). Throws on auth tag mismatch (tamper detection). Null-safe.
- `apps/api/src/utils/blindIndex.js` — HMAC-SHA256 blind index keyed by `BLIND_INDEX_KEY`. Normalizes input (lowercase + trim) before hashing. Enables equality queries on encrypted email field. Null-safe.
- `apps/api/src/models/AuditLog.js` — Mongoose model capturing actorId, actorRole, action (8-value enum), resourceType, resourceId, targetUserId, ip, userAgent, outcome, meta. Four compound indexes for admin query patterns. No TTL (HIPAA 6-year retention).
- `apps/api/src/middleware/auditLogger.js` — Express middleware factory. Fire-and-forget `AuditLog.create()` (no await). Intercepts `res.json`/`res.send` to capture final status code. Maps HTTP status to outcome (2xx=success, 401/403=blocked, else=failure). Never throws on write failure.
