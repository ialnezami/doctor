# Phase 5.2 Plan 07: GDPR Right to Erasure and Consent Withdrawal Summary

One-liner: Transactional GDPR Article 17 erasure service anonymizing PHI across 6 collections inside a MongoDB session, with patient-only privacy endpoints for erasure, consent withdrawal, and audit trail access.

## What Was Built

### Task 1: erasureService.js

`apps/api/src/services/erasureService.js` implements the full GDPR erasure flow:

**checkBlockingConditions(userId):** Pre-transaction guard that rejects erasure if:
- Patient has future `pending` or `confirmed` appointments (must cancel first)
- Patient has active SharedLinks (`revokedAt: null` + not expired — must revoke first)

**erasePatient(userId, { ip, userAgent }):** Runs inside `mongoose.startSession()` + `session.withTransaction()`:
1. User PII: anonymizes name, email (to `erased-{id}@deleted.invalid`), nulls emailHash/googleId/fcmToken/photoUrl; sets `erasedAt`, `dataProcessingAllowed: false`
2. Patient PHI: clears `medicalHistory: []`, `allergies: []`, `conditions: []`, `dateOfBirth: null`, `bloodType: null`, `notes: []`, `homeLocation: null`
3. ConsultationNote: sets `content: '[ERASED]'`, `aiAssist.patientSummary: null` for all appointments
4. Prescription: sets `instructions: '[ERASED]'`
5. LabResult: sets `notes: '[ERASED]'`, `aiInterpretation.summary: null`, `tests.$[].value: '[ERASED]'`
6. Message: hard-deletes all messages for this patient's appointments
7. Notification: hard-deletes all notifications for this patient
8. SharedLink: hard-deletes all (expired/revoked included for completeness)
9. Report: nulls `reporterId` (retains structure, removes identity)

Post-transaction: anonymizes `medications.$[].name/dosage/frequency/duration` (arrayFilters + session compatibility).

AuditLog entry with `action='erase'` written fire-and-forget after transaction.

**withdrawConsent(userId, { ip, userAgent }):** Sets `dataProcessingAllowed: false` + `consentWithdrawnAt`; writes audit entry with `action='consent'`. Grace period handled by retention worker (Plan 09).

### Task 2: privacy.js + index.js

`apps/api/src/routes/privacy.js` provides three patient-only endpoints:

- `DELETE /api/privacy/erase` — GDPR Article 17; returns 409 on blocking conditions
- `POST /api/privacy/consent/withdraw` — GDPR Article 7(3); returns grace period in response
- `GET /api/privacy/audit-log` — GDPR Article 15 transparency; last 100 audit entries

Registered in `index.js` as `app.use('/api/privacy', require('./routes/privacy'))`.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing functionality] SharedLink blocking check includes revokedAt: null**
- **Found during:** Task 1 implementation
- **Issue:** Plan spec said "active SharedLink tokens" — SharedLink model has a `revokedAt` field. A revoked-but-not-expired link should NOT block erasure; only links that are both non-revoked and non-expired block.
- **Fix:** Added `revokedAt: null` to the `checkBlockingConditions` SharedLink query alongside the expiry check.
- **Files modified:** `apps/api/src/services/erasureService.js`
- **Commit:** adaeaea

**2. [Rule 2 - Missing functionality] All four medication fields anonymized (not just name/dosage)**
- **Found during:** Task 1 implementation — reading Prescription model
- **Issue:** Plan spec mentioned name/dosage. The Prescription model has 4 PHI subdoc fields: `name`, `dosage`, `frequency`, `duration`. All are encrypted and constitute PHI.
- **Fix:** Post-transaction `medications.$[]` update anonymizes all four fields.
- **Files modified:** `apps/api/src/services/erasureService.js`
- **Commit:** adaeaea

**3. [Rule 2 - Missing functionality] Direct model imports instead of safeRequireModel()**
- **Found during:** Task 1 implementation
- **Issue:** Plan template used `safeRequireModel()` for Message, Notification, SharedLink (treating them as potentially absent). All three models exist in this codebase.
- **Fix:** Imported directly with `require()`. Cleaner code, no silent skips if models exist.
- **Files modified:** `apps/api/src/services/erasureService.js`
- **Commit:** adaeaea
